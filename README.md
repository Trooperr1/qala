# JAFF STUDIO - Multi-Page Website

An elite creative agency website featuring AI solutions, web development, and social media management services.

## 🌟 Features

- **Multi-Page Architecture**: Clean separation of content across different pages
- **3D Background**: Interactive Three.js particle system with animated elements
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Google Translate Integration**: Multi-language support for global reach
- **Smooth Animations**: GSAP-powered scroll animations and transitions
- **Contact Form**: Integrated with FormSubmit for easy form handling
- **Modern UI/UX**: Glassmorphism effects, floating elements, and premium design

## 🔧 Customization

### Update Contact Information
- Edit WhatsApp number in all HTML files: `https://wa.me/1234567890`
- Update FormSubmit email in `contact.html`: `contact@jaffstudio.com`

### Modify Colors
- Edit CSS variables in `css/styles.css`
- Main colors: Black (#000), White (#fff), Translucent white overlays

### Add New Pages
1. Copy an existing HTML file as template
2. Update navigation links in all files
3. Add corresponding styles in `css/styles.css`
4. Add JavaScript functionality in `js/scripts.js` if needed
